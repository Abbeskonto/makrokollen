# Makrokollen

Räkna kalorier, macros och micros med Livsmedelsverkets livsmedelsdatabas. En webbapp (PWA) som installeras på hemskärmen och fungerar offline. All data sparas lokalt i webbläsaren.

Näringsdata: Livsmedelsverkets livsmedelsdatabas, hämtad via dataportal.livsmedelsverket.se.

Märkesvaror och streckkoder: Open Food Facts (https://openfoodfacts.org), licens ODbL. Streckkodsläsning: html5-qrcode 2.3.8 (Apache-2.0) i vendor/.
